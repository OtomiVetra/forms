Этот проект создан для демонстрации работы с формами в React, с акцентом на:

- создание **многоразового компонента `CustomInput`**
- использование **настраиваемых форм** (`SignIn`, `SignUp`)
- **валидацию** данных вручную с помощью регулярных выражений (RegExp)
- гибкую стилизацию с помощью **Tailwind CSS**

---

## 📦 Состав проекта

### 🔧 `CustomInput.tsx`

Многоразовый компонент текстового поля с поддержкой:

- `label`, `placeholder`, `description`, `required`
- отображения ошибок (`error`)
- изменения стиля (цвет заливки, размер, скругление) через props:
    - `color`: `default` / `filled`
    - `size`: `sm`, `md`, `lg`
    - `radius`: `none`, `sm`, `md`, `lg`, `full`
- добавления иконки в поле (`icon`)
- полной интеграции с формами

### 🔐 `Signin.tsx`

Форма входа, содержащая:

- поле Email
- поле Пароль
- кнопку "Войти"
- локальную валидацию полей:
    - Email — проверка по RegExp
    - Пароль — минимум 6 символов, буквы и цифры
- принимает `onSubmit`, куда передаёт значения полей

### 📝 `Signup.tsx`

Форма регистрации, содержащая:

- поля: Имя, Ник, Почта, Пол (radio), Пароль, Повтор пароля
- валидация:
    - Имя — не пустое
    - Ник — начинается с буквы, не менее 3 символов
    - Email — валидный адрес
    - Пол — выбран
    - Пароль — буквы + цифры, не менее 6 символов
    - Повтор пароля — совпадает с паролем
- также принимает `onSubmit`, вызывается при успешной валидации
